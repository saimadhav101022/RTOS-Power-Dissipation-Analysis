# Analysis of Power Dissipation using RTOS

## Overview

This project investigates the effect of RTOS task scheduling and
power-management modes on power consumption in embedded systems.

FreeRTOS is used to implement multiple tasks, while an INA219 power
sensor is used to measure voltage, current, and power consumption.

## Objectives

- Analyze power consumption under RTOS-based scheduling
- Compare active, idle and sleep modes
- Measure voltage, current and power
- Study the effect of task execution on power consumption
- Identify power-efficient RTOS configurations

## Hardware

- ESP32 
- INA219 Power Sensor
- HC-SR04 Ultrasonic Sensor
- LEDs
- Battery / Power Supply

## Software
